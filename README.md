## 🌊 Постановка физической и математической задачи

Рассматривается плоская задача дифракции гармонической упругой волны, падающей из верхней полуплоскости $y > 0$ на границу $y = 0$.
Граница состоит из двух периодически повторяющихся участков с периодом $l$:
- $\mathcal{N}$ — участок **полного жесткого контакта** с основанием:
  $$u_x^{(0)}(x, 0) + u_x(x, 0) = 0, \quad u_y^{(0)}(x, 0) + u_y(x, 0) = 0 \quad (x \in \mathcal{N})$$
- $\mathcal{M}$ — участок **дефекта (отслоение / идеальное скольжение без трения)**:
  $$u_y^{(0)}(x, 0) + u_y(x, 0) = 0, \quad \tau^{(0)}(x, 0) + \tau(x, 0) = 0 \quad (x \in \mathcal{M})$$

Обратите внимание: нормальное перемещение $u_y^{tot}(x, 0) = u_y^{(0)}(x, 0) + u_y(x, 0) = 0$ **тождественно обращается в ноль** на всей границе раздела $y = 0$.

Падающая волна (индекс $(0)$) имеет номер гармоники $s$ с заданными амплитудами $B_s$ (продольная) и $D_s$ (поперечная).
Дифрагированное (уходящее) поле представляется в виде рядов по гармоникам Флоке с неизвестными коэффициентами $A_n$ (продольные моды) и $C_n$ (поперечные моды).

## 📐 Математический аппарат и формулы диссертации

### 1. Параметры среды и волновые числа (формулы 1.1, 1.5)
- Модули Ляме: $\mu = \rho v_s^2$, $\lambda = \rho v_p^2 - 2\mu$.
- Волновые числа: $k_1 = \frac{\omega}{v_p} = \sqrt{\frac{\rho \omega^2}{\lambda + 2\mu}}$, $k_2 = \frac{\omega}{v_s} = \sqrt{\frac{\rho \omega^2}{\mu}}$.
- Волновые числа гармоник Флоке: $L_n = \alpha + \frac{2\pi}{l} n$, где $\alpha = k_1 \cos(\theta)$ (угол $\theta$ от оси $Ox$).

### 2. Выбор ветвей корней $\beta_{jn}$ (п. 1.3 диссертации, стр. 16)
$$\beta_{jn} = \sqrt{k_j^2 - L_n^2} = \begin{cases} 
i \sqrt{L_n^2 - k_j^2}, & |L_n| \ge k_j \quad \text{(затухающие моды)} \\ 
-\sqrt{k_j^2 - L_n^2}, & |L_n| < k_j \quad \text{(бегущие волны в направлении $+y$)} 
\end{cases}, \quad j = 1, 2$$

### 3. Интегралы $I_k$ и $J_k$ (формулы 3.12)
$$I_k = \int_{\mathcal{M}} e^{i \frac{2\pi}{l} k t} dt, \quad J_k = \int_{\mathcal{N}} e^{i \frac{2\pi}{l} k t} dt$$
Для интервала дефекта $\mathcal{M} = (a, b) \subset [0, l]$ вычисляются аналитически:
- При $k = 0$: $I_0 = b - a$, $J_0 = l - I_0$.
- При $k \ne 0$: $I_k = \frac{e^{i \frac{2\pi}{l} k b} - e^{i \frac{2\pi}{l} k a}}{i \frac{2\pi}{l} k}$, $J_k = -I_k$.

### 4. Усечённая СЛАУ (формула 3.15)
$$l \tilde{C}_k - \frac{1}{l} \sum_{n=-N}^N \gamma_n \tilde{C}_n \sum_{m=-M}^M \frac{1}{\gamma_m} I_{n-m} J_{m-k} = \tilde{D}_s I_{s-k}, \quad k = -N, \dots, N$$
где:
- $\gamma_n = \frac{L_n^2}{\beta_{1n}} + \beta_{2n}$ (формула 3.10)
- $\tilde{D}_s = \frac{2 L_s (B_s \beta_{1s} + D_s)}{L_s^2 + \beta_{1s}\beta_{2s}}$
- Неизвестные $\tilde{C}_n$ в формулировке лабораторной обозначаются как $C_n^*$ (для $N = 7$ размер матрицы $15 \times 15$).

### 5. Обратный пересчёт (восстановление $C_n$ и $A_n$)
1. Восстановление $C_n$ из $\tilde{C}_n$ (стр. 16/27 диссертации):
   $$C_n = \tilde{C}_n \quad (n \ne s)$$
   $$C_s = \tilde{C}_s + \frac{2 B_s L_s \beta_{1s} + D_s (L_s^2 - \beta_{1s}\beta_{2s})}{L_s^2 + \beta_{1s}\beta_{2s}}$$
2. Восстановление $A_n$ из $C_n$ (формула 3.7):
   $$A_n = \frac{L_n}{\beta_{1n}} C_n \quad (n \ne s)$$
   $$A_s = \frac{L_s}{\beta_{1s}} (C_s - D_s) - B_s$$

### 6. Восстановление полей (формулы 3.3 и 3.4)
- **Дифрагированная волна**:
  $$u_x(x, y) = \sum_{n=-N}^N [A_n L_n e^{i\beta_{1n} y} + C_n \beta_{2n} e^{i\beta_{2n} y}] e^{i L_n x}$$
  $$u_y(x, y) = \sum_{n=-N}^N [A_n \beta_{1n} e^{i\beta_{1n} y} - C_n L_n e^{i\beta_{2n} y}] e^{i L_n x}$$
  $$\tau(x, y) = i \sum_{n=-N}^N [2 A_n \mu L_n \beta_{1n} e^{i\beta_{1n} y} + C_n (\rho\omega^2 - 2\mu L_n^2) e^{i\beta_{2n} y}] e^{i L_n x}$$
- **Полное поле**: $u_x^{tot} = u_x^{(0)} + u_x$, $u_y^{tot} = u_y^{(0)} + u_y$, $\tau^{tot} = \tau^{(0)} + \tau$.

## 🚀 Инструкция по запуску

### 1. Запуск базового расчета Блока 2 ($N = 7$):
```bash
python main.py
```
*Скрипт выведет параметры задачи, характеристики матрицы СЛАУ, таблицу коэффициентов $C_n^*, C_n, A_n$ от $-7$ до $+7$, невязки граничных условий и сохранит 4 графика в папку `output_plots/`.*

```bash
python -m unittest tests/test_slau.py
```
или (если установлен pytest):
```bash
pytest tests
```

### 3. Запуск численных экспериментов (в т.ч. из `Исходные данные.txt`):
```bash
python run_experiments.py
```

## 📊 Результаты расчета базовой задачи (Блок 2)

Для базовых параметров каучука ($v_p = 198$ м/с, $v_s = 54$ м/с, $\rho = 0.93$, $\omega = 150$ рад/с, $l = 2\pi$, дефект $\mathcal{M} = (0, \pi/2)$, $s = 0$, $B_s = 1$, $D_s = 1$):

1. **Характеристики СЛАУ**:
   - Размерность: $15 \times 15$ (индексы $n \in [-7, 7]$)
   - Число обусловленности: $\mathrm{cond}(A) \approx 2.133$ (система идеально обусловлена и устойчива).
2. **Полученные коэффициенты $A_n, C_n$ (фрагмент для центральных гармоник)**:
   - $n = -1$: $C_{-1} = 0.0206 + 0.0654 i, \quad A_{-1} = 0.0159 + 0.0507 i$
   - $n = 0$ ($s$): $C_0 = -0.9407 + 0.0345 i, \quad A_0 = 0.9407 - 0.0345 i$
   - $n = +1$: $C_1 = 0.0467 - 0.0468 i, \quad A_1 = -0.0538 - 0.0537 i$
3. **Проверка граничных условий**:
   - $\max |u_y^{tot}(x, 0)| \approx 8.46 \cdot 10^{-17}$ (точный машинный ноль на всем периоде).
4. **Сгенерированные графики**:
   - `boundary_conditions.png`: выполнение граничных условий на дефекте $\mathcal{M}$ и жестком контакте $\mathcal{N}$.
   - `elastic_fields_2d.png`: 2D карты распределения $|u(x, y)|$, $\mathrm{Re}(u_x)$, $\mathrm{Re}(u_y)$, $|\tau|$.
   - `coefficients_spectrum.png`: амплитудный спектр гармоник $|A_n|$ и $|C_n|$.
   - `convergence_study.png`: сходимость коэффициентов $C_s, C_{s\pm 1}$ при росте $N$ от 1 до 15.
